# RutgersDatingSim

INSTALLATION GUIDE as of 8/28/2026

Run on Windows 11

Requirements:
    Git for Windows
    Python ver 3.14
    Ren'Py ver 8.5.3

Cloning the Project

1) Download Git for Windows: go to https://git-scm.com/install/windows and follow instructions for downloading latest version (as of 8/28/2026 latest version is 2.55.0(5) x64)
2) launch Git Bash. This can be done by searching 'Git Bash" within the windows start menu and selecting the option for Git Bash
3) Clone the project to your Downlaods folder using the following commands
    a) cd Downloads
    b) git clone https://github.com/chb50/RutgersDatingSim.git

Download Python ver 3.14

1) go to: https://www.python.org/downloads/ and follow instruction to download latest version (as of 8/28/2026 latest version is 3.14)

Download Ren'Py ver 8.5.3

1) go to: https://www.renpy.org/latest.html and follow instructions to download latest version for Windows (as of 8/28/2026 latest version is 8.5.3)

Launch Game

1) search 'renpy.exe' in Window's start menu and click the option to launch Ren'Py
2) You will need to get Ren'py to point to the location of where you cloned the RutgersDatingSim project. Do the following:
    a) in the Main menu of Ren'Py select the "preferences" option at the bottom right
    b) in Preferences, select the "General" tab
    c) in the General tab, select the "Open Directory" option under the "Projects Directory" section
    d) There will be a popup window of your File system to select which folder to point to. In your case, select the "Downloads" folder and hit ok
    e) This should return you to the Preferences window. From here, Select the "Return" option at the bottom left of the Preferences window
    f) you should now be able to see the "RutgersDatingSim" option under the "Rutgersdatingsim" folder on the left of the Progects section of the main menu. select that option and hit "Launch Project" at the bottom left
